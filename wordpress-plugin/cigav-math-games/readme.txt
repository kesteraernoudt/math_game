A standalone, no-index math game portal at /math-games/.

== Description ==

Provides rounding, addition, payment, and change-making games in a standalone
interface. The plugin does not use the active theme and stores no game data on
the server.

== Installation ==

1. Upload and activate the plugin.
2. Visit /math-games/.
3. If necessary, save Settings > Permalinks once to refresh rewrite rules.
